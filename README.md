# DAAMS
## Digital Asset Access Monitoring and Risk Assessment System

DAAMS is a Windows-based security monitoring utility designed to monitor administrator-selected protected digital assets, assess potential security risks, record activity, and generate security alerts.

## Project Status
🚧 Currently in Development

## Main Features
- Protected File and Folder Monitoring
- Digital Asset Classification
- File/Folder Activity Logging
- Risk Assessment and Risk Scoring
- Security Alerts
- Incident Reports
- Email Notifications
- Windows Context Menu / Quick Actions

## Technology Stack
- Python — Monitoring Engine
- C# WPF — Administrator Console
- Firebase Firestore — Database
- Windows — Target Platform

## Development
The system is being developed incrementally. Features and components will be added and documented through Git commits.
